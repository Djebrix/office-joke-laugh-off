Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) — one original one-line office joke, judged pairwise by an AI comedy judge.

## The joke

> The intern asked where the fire exit was, so we pointed at the door marked 'Exit Interview'.

## How it works

`main.py` (Python 3, stdlib only) writes that single line to `/output/entry.txt`. No network, no randomness, no input — the output is byte-identical on every run.
